# Prompts photoréalistes — à générer gratuitement toi-même

Génère ces images avec un outil gratuit (Bing Image Creator / Copilot, Google ImageFX,
Leonardo.ai, Krea…), puis dépose-les dans le dossier `animation-nettoyage-3d/photos/`
avec **exactement** les noms de fichiers indiqués. Je les monte ensuite dans l'effet scroll.

## Règles pour que la série reste cohérente

1. **Génère l'image 1 en premier.** Si ton outil permet de réutiliser une image comme
   référence (« image de référence », « remix », « vary »), pars toujours de l'image 1
   pour les suivantes → même canapé, même pièce, même personne.
2. Garde ces éléments identiques d'une image à l'autre :
   - Canapé **3 places en tissu beige/taupe**, vu **de face**.
   - Salon **chic** : parquet clair, moulures, grande fenêtre à gauche, lumière naturelle chaude.
   - Une **personne** (même tenue : t-shirt bleu foncé, pantalon gris).
   - L'outil : **injecteur-extracteur vapeur à main, embout à tête transparente**.
3. Format **paysage 16:9**, rendu **photographique** (pas d'illustration, pas de 3D stylisée).
4. Récupère la **résolution la plus haute** possible.
